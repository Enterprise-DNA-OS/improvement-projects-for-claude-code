# Records first

The recurring work is deciding which improvement needs a review, checking the evidence behind claimed savings, and following up a control that slipped. An agent can run those jobs against the database and produce the A3 and benefit register.

The free base has no mobile capture, offline team synchronisation, drag-and-drop process map, simulation engine or vendor-hosted collaboration. Read-only HTML reports refresh when rendered; they are not a live application. Minitab Engage has its own project and visual tools. This system covers project evidence and review work, not every Engage feature.

Enterprise DNA builds the agreed screens, connections and additional documents into the business's version. Hosting, backups, access controls and agent usage have their own costs. No per-seat licence fee applies to this MIT code.
